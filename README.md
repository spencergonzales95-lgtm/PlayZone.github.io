# PlayZone

A responsive browser-game portal designed for GitHub Pages.

## Games included
- Amoeba Online
- Ragdoll — Sandbox Physics Game
- Undisputed MMA
- Helix Jump
- Bitcoin Wallet Simulator
- Gem Clicker
- Cookie Clicker (included locally in `cookie-clicker/`)

## Publish with GitHub Pages
1. Create a GitHub repository named `PlayZone` (or any name you like).
2. Upload **all files and folders** in this project. Make sure `index.html` is in the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site; open the URL shown in Settings → Pages.

## Notes
- The six iDev.Games titles load from their supplied third-party embed URLs. A host can block embedding or change its game; if one does not load, use the in-page “Open game in new tab” button.
- Cookie Clicker is stored in this repository and loads from `cookie-clicker/index.html`.
- The supplied Cookie Clicker source includes its own copyright/hosting notice. Keep that notice intact and review its README/source terms before redistributing or modifying it.
